# Fitlog 제품화 테스트 코드·시나리오 · 2026-10-11

## 담당과 상태
사용자는 실제 사용감과 대상 기기의 수용을 평가한다. 에이전트는 승인된 자동 테스트 코드·합성 환경 실행·결함 수정을 맡는다. 실제 AI/호스트 접근, 외부 모델 호출 비용·개인 이미지 전송은 해당 환경/기존 승인 범위를 확인한다. 아래 예정 시나리오를 구현/통과로 표기하지 않는다. 현재 실제 Codex/모바일/AI 첨부 수용은 미검증이다.

각 실행은 요구 ID, 시나리오 ID, 커밋/앱/호스트/모델 버전, 환경, 합성 fixture, 사전 조건, 실행 명령, 기대값/실제값, 통과·실패·미검증, 로그/스크린샷/trace, 담당과 이월을 남긴다. 실제 건강 데이터·이미지·토큰은 로그에 남기지 않는다. 신뢰할 수 있는 DB/도구 반환과 화면을 답변의 기준으로 삼으며 AI의 성공 주장만으로 판정하지 않는다.

2. 실제 stdio MCP: scripts/test-mcp.mjs. 실제 서버 프로세스의 discovery, 리소스, CRUD, 버전 충돌, 재시작, 도움말을 검사한다. scripts/test-backup.mjs와 test-probe.mjs는 백업 및 MCP 초기화를 검사한다.
3. 브라우저 UI: scripts/test-compact-ui.mjs → test-journal-ui.mjs. 실제 React + 임시 SQLite, HTTP test bridge/모사 AI. PC/좁은 화면·키보드·상태 갱신을 검증한다. 실제 MCP Apps iframe/권한/Codex 채팅은 이 계층에서 증명하지 않는다.
4. MCP Apps 통합 에뮬레이션: MCP Inspector + Playwright를 후속 후보로 사용한다. 실제 서버와 iframe/브리지/리소스/CSP 조합을 확인한다. 현재 설치·실행하지 않았으며 Inspector 버전별 stdio 지원/Apps 호환성을 확인한 뒤 고정한다. HTTP 예제를 그대로 쓰기 위해 Fitlog 서버를 외부 공개하지 않는다.
5. 실제 AI 평가: promptfoo MCP 연결 chat provider 또는 사용 중인 에이전트의 실제 실행 adapter로 도구 선택·인자·순서·최종 답변을 평가한다. MCP 직접 provider 호출은 도구 평가이며 AI의 도구 선택 검증이 아니다. 현재 미구현/미실행. API 모델 평가가 Codex 데스크톱 플러그인 수용을 대신하지 않는다.
6. 실제 대상 호스트: Codex의 새 카드/새 채팅에 설치된 버전으로 핵심 흐름을 검증한다. 모바일 호스트가 정해지면 모바일 연결/파일 접근/기기 전환도 검증한다. 현재 PC 로컬 DB가 다른 기기에 자동 동기화되는 구조는 없다.

## 실행과 단계 전이
기본: pnpm typecheck, pnpm build, pnpm test. UI: node --import tsx scripts/test-compact-ui.mjs. 새 실패를 수정한 뒤 관련 검증을 재실행한다. 실패 기준 삭제/수정으로 통과를 만들지 않는다. 사용자 원본 DB/사진은 시험 대상으로 사용하지 않는다.
구체화에서 시나리오/범위/합격 기준을 정한다. MVP에서는 핵심 성공/실패와 실제 대상 호스트 수용을 확보한다. 제품화에서는 승인 범위의 전체 핵심 시나리오와 회귀 자동화·권한·복구·상태 최신화를 검증한다. 출시 전 핵심 실패/미검증은 차단, 비핵심 이월은 담당/이유/후속 범위와 승인 근거를 남긴다. 테스트 문서/도구 추천만으로 상태를 바꾸지 않는다.

## 도구 추천과 조사 출처
2026-10-11 공식 자료 확인. 현재 추가 설치/외부 모델 평가를 실행하지 않았다.
- **Playwright Test**: PC/모바일 viewport, touch/device 설정, locale/timezone, 색상, 권한과 네트워크를 에뮬레이션하고 기존 React harness를 재사용한다. 모바일 OS 자체 에뮬레이터는 아니다. https://playwright.dev/docs/emulation
- **MCP Inspector + Playwright**: 서버 discovery/실호출·앱 리소스와 sandbox 렌더링을 검사한다. Inspector는 MCP Apps 통합 확인용 호스트이고 특정 AI 제품 전체를 복제하지 않는다. https://github.com/modelcontextprotocol/inspector/blob/main/docs/mcp-app-review.md
- **promptfoo**: MCP 직접 호출 또는 MCP연결 chat provider 평가. 실제 도구 호출 metadata.toolCalls로 라우팅/인자/오류·답변을 함께 검증한다. 모델 비용·fixture 전송 범위/사용할 모델은 착수 시 확인한다. https://www.promptfoo.dev/docs/providers/mcp/
- **Google ARTEMIS + Android Emulator**: 실기기와 에뮬레이터 모두 지원하며 자연어 Android 조작·로그·replay에 적합하다. 모바일 OS와 호스트 앱이 필요한 후속 단계 후보다. PC 플러그인·iOS·기기 간 동기화를 대신 검증하는 도구로 보지 않는다. https://github.com/google/artemis

Fitlog 추천 순서: 기존 코드/실제 stdioMCP → Playwright 반응형 회귀 → Inspector Apps 실제 브리지 → 실제 AI도구/답변 평가 → 대상 Codex/모바일 호스트 수용. 에뮬레이터 결과와 실제 호스트 결과는 항상 분리한다.
